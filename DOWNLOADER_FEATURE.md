## 🎵 YouTube Downloader Feature

Dashboard untuk download musik dan video dari YouTube tanpa iklan.

### Quick Access
```
http://localhost:20127/downloader
```

### Features
- ✅ Download MP3 (audio only)
- ✅ Download MP4 (video + audio)
- ✅ Paste YouTube URL langsung
- ✅ Mobile responsive
- ✅ No ads, no login required

### Quick Start
```bash
# Windows
start-downloader.bat

# Mac/Linux
bash start-downloader.sh

# Manual
npm run dev
# Open http://localhost:20127/downloader
```

### How It Works
1. Paste YouTube URL
2. Click MP3 or MP4
3. Download starts automatically
4. File saved to device

**Built with:** Next.js + ytdl-core + Tailwind CSS
